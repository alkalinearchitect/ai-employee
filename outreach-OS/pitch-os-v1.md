# OWL GOLDEN CIRCLE
## WHY sells the idea
```
WHY  →  what you believe
     →  the problem you refuse to accept

HOW  →  your methodology
     →  what makes you different

WHAT →  the product/outcome
     →  only 10% of the decision
```
Rule: lead WHY. Close WHAT. Prove HOW with live proof.

# OWL SCREENDECK — OUTPUT SPEC
## Every page must do one of these only
```
PAGE TYPES
- Cover
- Why / context
- Problem/pain
- Evidence
- Solution
- Proof/case study
- Implementation

### Layout
- 16x9 only
- max 4 bullets per slide (3 is better)
- one headline per slide
- one visual per slide
- text < 40 words
- black + white + one accent ONLY
- font: one heading face, one body face, 32/24/16/12
- numbered slides only
- last slide always: one contact action, one recurving CTA

# PITCH COPY — OWL RULES
## Copy style
- no adverbs
- no adjectives unless named or proven
- no “we believe” — use proven
- open with pain not product
- make claims arguable or stop

## OWL OPENING TEMPLATE
```
Problem:
    [exact specific pain]

    [specific hard metric — live date + source]

    [exact repeatable process]

# OUTREACH OS
## Four-way scoring filter
Score every outreach only on:
1. urgency — is the pain now?
2. economic impact — specific ££
3. quantified — has the user named hours/sales/leads
4. decision visibility — can you speak to the owner today

Personalisation stack:
```
First line: claimant observation — not generic
Second line: specific reclaim figure — live
Third line: one closing prompt — Y/N or time slot
Signature: bot url or direct phone — not faceless
```

# CLOSE FRAMEWORK
## Repeat if stalled
```
Assume close:
    “The reason I wanted to bring [X] in today is because
     [exact pain]. If I can show you that for £[P], [exact outcome],
     can we agreed to do that today?”
```

Low-risk close:
    “If I told you we could [exact outcome], would it be
     worth 20 minutes right now?”
Yes-presumptive:
    “So we’re going with [exact scope] on [exact date]?”
Either:
    “If we could solve [exact pain] in 48 hours with
     [exact payout], which side of this are you on?”
